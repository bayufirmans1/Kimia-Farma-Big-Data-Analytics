Kimia Farma Performance Dashboard
Overview

This project analyzes Kimia Farma’s sales and business performance using transactional, product, inventory, and branch data. The analysis focuses on key performance indicators, sales trends, regional performance, branch evaluation, and product profitability to support data-driven decision making.

Key Features

KPI overview: Total Sales, Total Profit, Transactions, Customers, and Average Rating

Yearly profit trend analysis

Regional performance analysis with geographic visualization

Branch performance evaluation using customer ratings

Product profit distribution analysis

Tools

Google BigQuery (data preparation & analysis)

SQL (BigQuery Standard SQL)

Looker Studio (dashboard visualization)
